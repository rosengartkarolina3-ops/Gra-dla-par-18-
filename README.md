# Gra dla par 18+ — Namiętne Wyzwania

**Aktualna wersja:** plik `index.html` w głównym katalogu tego repozytorium. Archiwum `gra-dla-par-18-starter.zip` jest starszą kopią startową.

## Funkcje
- Wariant **we dwoje (2 osoby)** z osobnymi punktami i naprzemiennymi turami.
- Wariant **grupowy (4–10 osób)**: Kobiety kontra Mężczyźni oraz Para kontra Para, z oddzielnymi rankingami.
- Dziewięć poziomów i pięcioetapowy **Finał Główny**.
- Rozbudowane, zmysłowe talie 18+ na poziomach 7–9, edytowalne karty, możliwość tworzenia własnych kart solo/duo. 
- Każda osoba indywidualnie wyraża zgodę,  może pominąć kartę bez kary i zatrzymać grę.
- Losowanie bez powtórek, punktowanie po potwierdzeniu, lokalny zapis postępu.

## Uruchomienie na telefonie
Otwórz `index.html` w przeglądarce lub opublikuj repozytorium przez **Settings → Pages → Deploy from a branch → main → /(root)**.
Po wdrożeniu: https://rosengartkarolina3-ops.github.io/Gra-dla-par-18-/

## Ograniczenia
Gra działa **na jednym urządzeniu/przeglądarce**. Nie synchronizuje telefonów, nie ma kodu pokoju ani serwerowej bazy danych. Udostępnienie linku innym osobom otwiera oddzielne lokalne sesje. Zmiany kart i punkty zapisują się w `localStorage` danego urządzenia.
